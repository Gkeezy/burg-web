# Multiplayer through this site

| Mode | Works on github.io? |
|------|---------------------|
| Practice (offline) | Yes |
| JOIN WEB to a host tunnel | Yes — paste `wss://…/ws` or use `?ws=` |
| Host from the browser | No — browsers cannot listen |
| Always-on free dedicated server | Not included (needs a host account / VPS) |

Deep link example (URL-encode the WSS):

```
https://gkeezy.github.io/burg-web/?ws=wss://example.trycloudflare.com/ws
```
